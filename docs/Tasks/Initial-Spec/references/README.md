# References

Dieser Ordner enthält keine Vollkopien der referenzierten Hersteller- oder Normdokumente. Stattdessen gibt es:

- `reference_index.md` - vollständiger Quellenindex mit URLs.
- `reference_index.pdf` - kurzer PDF-Index für Weitergabe/Review.
- `url/*.url` - anklickbare InternetShortcut-Dateien.
- `snapshots/*.md` - kurze Notizen zu den Quellen, ohne lange Zitate.

Grund: Viele Quellen sind urheberrechtlich geschützt, teils mit Download-Lizenz, und einige Sierra-Dokumente sind proprietär bzw. passwortgeschützt. Die Spec soll daher sauber referenzieren, aber keine Drittanbieter-PDFs redistributieren.
