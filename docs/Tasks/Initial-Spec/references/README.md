# References

Dieser Ordner ist primaer als Quellenindex gedacht. Die Unterordner enthalten:

- `reference_index.md` - vollständiger Quellenindex mit URLs.
- `reference_index.pdf` - kurzer PDF-Index für Weitergabe/Review.
- `url/*.url` - anklickbare InternetShortcut-Dateien.
- `snapshots/*.md` - kurze Notizen zu den Quellen, ohne lange Zitate.
- `downloads/` - lokal heruntergeladene Arbeitskopien, soweit anonym und offiziell abrufbar.

Hinweis: Viele Quellen sind urheberrechtlich geschützt, teils mit Download-Lizenz, und einige Sierra-Dokumente sind proprietär bzw. passwortgeschützt. Die Spec soll daher sauber referenzieren; lokale Arbeitskopien aus `downloads/` sind nicht automatisch zur Redistribution freigegeben.
