# Profil: 3gpp-27007-r18 und 3gpp-27005-r16

## Zweck

Normative Mobilfunkbasis für GSM/UMTS/LTE/5G-orientierte AT-Kommandos.

## 3GPP TS 27.007 - Pflichtumfang v1

| Befehl | Status | Beschreibung |
|---|---|---|
| `+CGMI` | full | Manufacturer identification. |
| `+CGMM` | full | Model identification. |
| `+CGMR` | full | Revision identification. |
| `+CGSN` | full | Serial number / IMEI. |
| `+CPIN` | full | SIM PIN / SIM state. |
| `+CMEE` | full | Mobile equipment error reporting mode. |
| `+CREG` | full | Network registration. |
| `+CGREG` | stub | GPRS registration, optional. |
| `+CEREG` | stub | EPS registration, optional. |
| `+CSQ` | full | Signal quality. |
| `+COPS` | read | Operator read from XML profile; selection optional. |
| `+CCLK` | stub | Clock. |
| `+CFUN` | stub | Functionality level. |

## 3GPP TS 27.005 - Pflichtumfang v1

| Befehl | Status | Beschreibung |
|---|---|---|
| `+CMGF` | full | SMS Text/PDU mode selection. |
| `+CMGS` | full | Send SMS with prompt and Ctrl-Z. |
| `+CMGR` | stub | Read SMS. |
| `+CMGL` | stub | List SMS. |
| `+CMGD` | stub | Delete SMS. |
| `+CNMI` | stub | New message indications. |
| `+CPMS` | stub | Preferred message storage. |
| `+CSCA` | stub | SMS service center address. |
| `+CSCS` | stub | Character set. |

## CME/CMS-Fehler

Wichtige CME-Codes für v1:

| Code | Text |
|---:|---|
| 3 | operation not allowed |
| 4 | operation not supported |
| 10 | SIM not inserted |
| 11 | SIM PIN required |
| 12 | SIM PUK required |
| 13 | SIM failure |
| 14 | SIM busy |
| 15 | SIM wrong |
| 30 | no network service |
| 31 | network timeout |
| 50 | incorrect parameters |

Wichtige CMS-Codes werden zunächst frei konfigurierbar gehalten, weil Hersteller bei SMS-Fehlern häufig abweichen.
