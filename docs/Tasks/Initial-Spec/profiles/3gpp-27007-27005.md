# Profil: 3gpp-27007-r18 und 3gpp-27005-r16

## Zweck

Normative Mobilfunkbasis für GSM/UMTS/LTE/5G-orientierte AT-Kommandos.

## 3GPP TS 27.007 - Pflichtumfang v1

| Befehl | Status | Beschreibung |
|---|---|---|
| `+CGMI` | `implemented_full` | Manufacturer identification. |
| `+CGMM` | `implemented_full` | Model identification. |
| `+CGMR` | `implemented_full` | Revision identification. |
| `+CGSN` | `implemented_full` | Serial number / IMEI. |
| `+CPIN` | `implemented_full` | SIM PIN / SIM state. |
| `+CMEE` | `implemented_full` | Mobile equipment error reporting mode. |
| `+CREG` | `implemented_full` | Network registration. |
| `+CGREG` | `implemented_stub` | GPRS registration, deterministic stub or profile output. |
| `+CEREG` | `implemented_stub` | EPS registration, deterministic stub or profile output. |
| `+CSQ` | `implemented_full` | Signal quality. |
| `+COPS` | `implemented_full` | Operator read from XML profile; selection optional. |
| `+CCLK` | `implemented_stub` | Clock. |
| `+CFUN` | `implemented_stub` | Functionality level. |

## CME/CMS-Fehler

Wichtige CME-Codes für v1:

| Code | Text |
|---:|---|
| 3 | operation not allowed |
| 4 | operation not supported |
| 10 | SIM not inserted |
| 11 | SIM PIN required |
| 12 | SIM PUK required |
| 13 | SIM failure |
| 14 | SIM busy |
| 15 | SIM wrong |
| 30 | no network service |
| 31 | network timeout |
| 50 | Incorrect parameters |

Wichtige CMS-Codes werden zunächst frei konfigurierbar gehalten, weil Hersteller bei SMS-Fehlern häufig abweichen.
